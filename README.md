# 🎵 Spotify Clone

A Spotify-inspired music player website built using
HTML, CSS and JavaScript.

## Features
- Music playback
- Play / pause controls
- Next / previous song
- Progress bar
- Shuffle and repeat
- Song search
- Responsive interface

## Technologies
- HTML5
- CSS3
- JavaScript
- Font Awesome
